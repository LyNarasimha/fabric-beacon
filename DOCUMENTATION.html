Goal

Build an internal discovery platform so the team can search, browse, and understand every Power BI / Fabric asset in scope — with lineage, governance scores, and refresh health in one place.

Description

Fabric Beacon is a centralized catalog for workspaces, datasets, reports, paginated reports, measures, columns, and DAX/M definitions. It replaces portal-hopping with deep search, reverse lookup, interactive lineage, and workspace-level governance so anyone can find what exists, what it depends on, and whether it is still trustworthy.

Success looks like

Every in-scope workspace is synced into a searchable catalog; any report, dataset, table, column, or measure can be found in seconds; lineage shows source → model → report clearly; governance surfaces stale datasets and orphaned measures; refresh status is visible; analysts self-serve without admin help.

What we can achieve

One source of truth instead of scattered bookmarks; faster impact analysis before model changes; proactive governance; fewer duplicate reports; a foundation for data trust and release readiness.

What we can use it for

Onboarding; “which reports use this table or measure?” before a change; workspace health before a release; stale content cleanup; migration decisions; leadership view of the BI estate.

How it works

Setup — once

  1. Clone the engineering repo (see README on GitHub).
  2. Run .\start-dev.ps1 → open the app in the browser.
  3. Use Demo with no credentials, or complete Setup for live Power BI / Fabric.
  4. Optional: connect Jira for ticket analyzer flows.
You are done when you can open Discovery, search a report name, and open lineage for a dataset.

Daily use

Before a model or report change: search the table or measure → open lineage → note impacted reports. For tickets: open Jira analyzer with the ticket key. Before release: check governance and refresh health for the workspace.
